# Stormfall · Tactical Royale

A single-file browser tactical battle royale game.

## Play

Open `index.html` in a modern browser — no build step or server required.
(Fonts load from Google Fonts; everything else is inline.)

## Files

- `index.html` — the full game (HTML, CSS and JS in one file)
- `assets/icon-512.png` — favicon / app icon
- `assets/apple-touch-icon.png` — iOS home-screen icon
